# Minecraft Operations Runbook Index

A lightweight catalog that helps operators find the right procedure during routine work and incidents. Keep this index current as services and ownership change.

## Runbook quality bar
Each linked runbook should name its owner, last review date, prerequisites, safe execution steps, verification signals, rollback, escalation path, and data-handling constraints. Prefer tested procedures over tribal knowledge. Runbooks must not embed credentials or private player information.

Review high-risk procedures quarterly and after material architecture changes. Test recovery steps in staging before relying on them in production.
